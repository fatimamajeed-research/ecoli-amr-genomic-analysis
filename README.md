# Genomic Analysis of Antimicrobial Resistance in Escherichia coli

## Project Status

In Progress

## Overview

This project aims to investigate genomic features associated with antimicrobial resistance (AMR) in Escherichia coli using publicly available genomic and antimicrobial-resistance data.

## Objectives

- Explore genomic and AMR data from E. coli isolates.
- Analyze the distribution of antimicrobial-resistance genes.
- Investigate the co-occurrence of AMR genes.
- Explore associations between genomic features and antimicrobial resistance.
- Explore how genomic findings may contribute to AMR model interpretation.

## Data Source

Publicly available E. coli genomic and antimicrobial-resistance data.
